# FXT Team New Tab — быстрая установка

1. Скачайте и запустите установщик для своей системы.
   - **Windows** — дважды щёлкните по скачанному файлу [install.cmd](https://github.com/AenyellHael/browser-startpage-extension/releases/latest/download/install.cmd).
   - **Linux** — скачайте [install.sh](https://github.com/AenyellHael/browser-startpage-extension/releases/latest/download/install.sh) и выполните `sh ./install.sh` в папке загрузки. Понадобится Python 3.
2. Когда установщик предложит ежедневные автообновления, выберите **Да** или **Нет**.
3. В Chrome откройте `chrome://extensions`, включите **Режим разработчика** и нажмите **Загрузить распакованное расширение**. Выберите папку `extension`, путь к которой покажет установщик.
