# FXT Team New Tab — 1.4.1

## Что делает

При создании новой вкладки (`+`, Ctrl+T) открывает https://homepage.fxtteam.ru/.
При запуске Chrome дополнительных вкладок не создаёт. После загрузки сайта
фокусом строки поиска управляет сама стартовая страница.

## Что нового в 1.4.1

Расширение проверяет доступность страницы запросом HEAD. Если сервер отвечает
405 или 501, расширение повторяет проверку через GET. Обе попытки используют
общий тайм-аут в шесть секунд. Удалён скрипт выбора первого поля ввода.

## Что нового в 1.4.0

Пока расширение проверяет доступность сайта, вкладка показывает локальный прелоадер из browser-startpage. При ошибке или ожидании дольше шести секунд появляется кнопка «Попробовать снова».

## Исправление

В версии 1.1.0 JavaScript находился прямо внутри newtab.html, что запрещено
Content Security Policy для расширений Manifest V3. В версии 1.2.0 скрипт
вынесен в отдельный newtab.js.

## Установка

1. Распакуйте ZIP в постоянную папку.
2. Откройте chrome://extensions.
3. Удалите старую распакованную версию FXT Team New Tab, чтобы избежать конфликта.
4. Включите режим разработчика и нажмите «Загрузить распакованное расширение».
5. Выберите папку расширения, содержащую manifest.json.
6. Нажмите + для проверки.

## Важно

Chrome может предложить подтвердить изменение страницы новой вкладки.
Переход на сайт зависит от его доступности; фокус поля зависит от разметки сайта.
Распакованная версия не гарантирует синхронизацию на других ПК. Для распространения
через синхронизацию обычно требуется установка из Chrome Web Store.
